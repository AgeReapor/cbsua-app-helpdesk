# Offices

The `HD Office` DocType represents a CBSUA service destination. Office Name and Office Code are unique identifiers; Enabled controls whether customers can select it; Default Office selects the fresh-ticket fallback (ICT on initial installation).

The baseline offices are ICT Office, Registrar's Office, Admissions Office, and Cashier's Office. Add future offices through the Desk and configure their teams and request types independently.
