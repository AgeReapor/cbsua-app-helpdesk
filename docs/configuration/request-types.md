# Office Request Types

`HD Office Request Type` belongs to exactly one `HD Office`. Request type codes are globally unique, allowing the same display label (for example, Inquiry) to be configured separately for multiple offices.

Fresh installation creates Tech Support and Inquiry for ICT, and Inquiry for Registrar, Admissions, and Cashier. Add or disable request types independently without code changes. The server validates that the selected type is enabled and belongs to the ticket's selected office.
