# MVP 1 Office Routing Acceptance Tests

- [ ] Fresh install creates ICT, Registrar, Admissions, and Cashier offices.
- [ ] ICT has Tech Support and Inquiry.
- [ ] Registrar, Admissions, and Cashier each have Inquiry only.
- [ ] ICT is the default office on a fresh install.
- [ ] Re-running bootstrap creates no duplicate rows and preserves administrator edits.
- [ ] A request type can be added to one office without changing another office.
- [ ] New tickets reject disabled offices and request types belonging to another office.
- [ ] A team can serve multiple offices when each is explicitly mapped.
- [ ] Ticket assignment rejects a team not mapped to the ticket office.
- [ ] A non-member cannot resolve a ticket assigned to an office team.
- [ ] Existing tickets without office metadata are not silently reassigned.
- [ ] Customer portal request type options are filtered by selected office.

- [ ] Helpdesk workspace shows a CBSUA Office Routing card with Offices and Office Request Types links.
- [ ] HD Settings shows a CBSUA Routing tab with the default office selector.
- [ ] CB Office and CB Office Request Type Link fields are selectable by Administrator and System Manager.
- [ ] Existing HD Team records expose Assigned Offices and save CB Team Office rows.
